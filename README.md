# My Budget Tracker

## About the Project

My Budget Tracker is a simple web application designed to help users organize and track their expenses. This week's assignment focuses on improving the visual design of the existing Budget Tracker using CSS.

## What I Improved

### 1. Color Palette

I used a consistent blue, white, and light-gray color palette throughout the application.

The colors are used for:

- Page background
- Headings
- Buttons
- Table headers
- Cards
- Form elements

### 2. Typography

I used Google Fonts to improve the appearance and readability of the application.

- Poppins is used for headings and buttons.
- Roboto is used for normal body text, labels, and table content.

### 3. Table Styling

The expense table includes:

- Styled table headers
- Borders
- Padding
- Alternating row colors
- Hover effects
- Rounded visual sections

### 4. Form Styling

The Add Expense form includes:

- Styled labels
- Input fields
- Category selection
- Spacing between form elements
- Rounded input borders
- Styled Add Expense button

### 5. CSS Box Model

I used the CSS Box Model throughout the project.

I applied:

- Margin to separate sections
- Padding to create space inside cards
- Borders to define sections
- Border-radius to create rounded corners

The page heading, Add Expense form, and Expense Table are displayed as separate cards.

## Files

- `index.html` - Contains the structure and content of the Budget Tracker.
- `style.css` - Contains the visual styling and layout.
- `README.md` - Explains the project and the improvements made.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
